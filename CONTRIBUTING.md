# Contributing

Issues and pull requests are welcome.

This repository is generated from an internal repository, so pull requests are not merged here. If we accept yours, we land it internally, sometimes with small changes, and close the pull request here. It ships in the next release, where you are credited as a co-author.

Before opening a pull request, run `make style`, `make typecheck`, and `make test`, plus `make config` if you changed model configs.
